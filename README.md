### 🔐 Password Checker

After completing Chapter 4, I built a simple password checker to practice the Python concepts I had learned so far.

The program checks a password for:

* Minimum length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

It then gives the password a score out of 5 and classifies it as strong, moderate, or weak.
