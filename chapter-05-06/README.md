# Login Security Simulator

A beginner Python cybersecurity project that simulates a basic login security system.

## What I Practiced

* Variables
* User input
* Conditional statements
* While loops
* Boolean values
* Comparisons
* Counters
* Basic password validation
* Controlling login attempts

## Security Features

The program:

* Checks a username and password
* Allows multiple login attempts
* Limits users to 3 attempts
* Displays remaining attempts
* Grants access when the correct credentials are entered
* Locks the account after 3 failed attempts
* Checks whether the stored password meets a minimum length requirement

## What I Learned

This project helped me understand how basic authentication systems can control access and respond to repeated failed login attempts.

It also gave me practical experience applying Python fundamentals to a cybersecurity-related problem.

## Current Limitations

This is a beginner educational project and is **not a production authentication system**.

The username and password are stored directly in the Python code, and the project does not yet use encryption, hashing, databases, or external authentication services.

These are concepts I plan to explore later as I progress through my cybersecurity learning journey.
